## I. L'atome : de quoi est faite la matière ?

Toute la matière qui nous entoure — l'eau, l'air, ton corps — est composée d'**atomes**. Un atome est l'entité la plus petite d'un élément chimique qui conserve ses propriétés. Il est constitué de deux parties : un **noyau** central très dense, et un **cortège électronique** qui l'entoure.

#### 📖 Étymologie

Le mot **atome** vient du grec ancien : a- (négation) + tomos (coupé) = **"non sécable"**, c'est-à-dire "qui ne peut pas être divisé". Les philosophes grecs pensaient que l'atome était la plus petite particule indivisible de matière. Aujourd'hui, on sait que l'atome lui-même est divisible (noyau + électrons), mais le nom est resté !

### Représentation de l'atome

On représente un atome X par la notation suivante :

Notation de l'atome

Z

Où :

- **X** : symbole de l'élément chimique (H, C, O, Fe…)

- **Z** : **numéro atomique** = nombre de protons dans le noyau. C'est lui qui définit l'élément.

- **A** : **nombre de masse** = nombre total de nucléons (protons + neutrons) dans le noyau

**💡 Pourquoi N = A − Z ?**

Le **nombre de masse A** représente le **total de tous les nucléons** dans le noyau (protons + neutrons).

Le **numéro atomique Z** représente uniquement le **nombre de protons**.

Donc logiquement : **A** (protons + neutrons) **− Z** (protons) **= N** (neutrons)

**A = Z + N** ⟹ **N = A − Z**

#### 🔑 Comment compter les particules grâce à la notation

La notation

- **Nombre de protons** : directement donné par **Z** (numéro atomique)

- **Nombre de neutrons** : se calcule par **N = A − Z** (différence entre le nombre de masse et le numéro atomique)

- **Nombre d'électrons** :

- Pour un **atome neutre** : **Z électrons** (autant que de protons)

- Pour un **cation X n+ ** : **Z − n électrons** (l'atome a perdu n électrons)

- Pour un **anion X n− ** : **Z + n électrons** (l'atome a gagné n électrons)

### 1️⃣ Nucléide : l'identité complète d'un atome

**Définition :** Un **nucléide** est une espèce atomique définie par **A ET Z**. C'est comme une carte d'identité complète de l'atome.

💡 Ce sont deux nucléides **différents** car ils n'ont pas le même A (même s'ils ont le même Z).

### 2️⃣ Élément : la famille chimique

**Définition :** Un **élément** est défini par **Z uniquement** (nombre de protons). C'est la famille chimique (il existe 118 éléments dans le tableau périodique).

**Exemple concret :**

**⚠️ ATTENTION : Ne confonds pas !C'est Z (les PROTONS) qui définit l'élément, PAS les électrons !**

- **Cl neutre** : 17 protons, 17 électrons → élément **chlore**

- **Cl⁻** (ion) : 17 protons, **18 électrons** → toujours élément **chlore** (car Z = 17) !

**🔑 Règle absolue :** Un élément est **toujours** défini par son **nombre de protons (Z)**, même si le nombre d'électrons change (ions).

**💡 Alors pourquoi parle-t-on des électrons ?**

Parce que **Z définit l'élément** (identité), mais ce sont **les électrons qui font la chimie** :

- Les **protons** restent dans le noyau → ils ne bougent jamais → **identité stable**

- Les **électrons** (surtout ceux de la couche externe) → participent aux liaisons → **propriétés chimiques**

- Pour un **atome neutre** : Z protons = Z électrons → les isotopes (même Z) ont donc les mêmes propriétés chimiques

## IV. La mole et les grandeurs de masse

Imagine : un atome est **tellement petit** qu'on ne peut pas le manipuler seul. C'est comme vouloir compter les grains de sable d'une plage un par un : **impossible** ! On a donc inventé des unités pour passer du monde des atomes (microscopique) au monde réel (macroscopique, ce qu'on peut peser).

#### 🎯 Le problème à résoudre

**Comment relier :**

- 👉 **Un atome** (minuscule, invisible) ⬅️ monde MICROSCOPIQUE

- 👉 **1 gramme de matière** (visible, pesable) ⬅️ monde MACROSCOPIQUE

💡 Solution : La **MOLE** = l'unité qui fait le pont entre les deux mondes !

### 1️⃣ Le nombre d'Avogadro : le pont magique

**Définition :** Le **nombre d'Avogadro** N A = **6,022 × 10²³🔢 Imagine ce nombre énorme :**

- C'est un **6** suivi de **23 zéros** : 602 200 000 000 000 000 000 000 !

- Si tu comptais 1 atome par seconde, il te faudrait **19 000 milliards d'années** pour arriver à N A

- Si tous les humains comptaient ensemble 24h/24, il faudrait **240 milliards d'années**

💡 Pourquoi ce nombre précisément ? Parce qu'on a décidé que **12 grammes de
12
C
contiennent exactement N A atomes**.

### 2️⃣ La mole : compter par paquets géants

**Définition :** Une **mole** (symbole : **mol**) = un paquet de N A entités (atomes, molécules, ions…)

**🎁 Comprendre la mole : c'est une unité de comptage (comme "douzaine", "vingtaine"...)**

💡 Pourquoi a-t-on inventé la "mole" ?

Au lieu de dire "6 022 000 000 000 000 000 000 000 atomes" (illisible !), on dit simplement **"1 mole"**. C'est juste une façon pratique de compter les atomes par gros paquets !

🔢 L'analogie avec la douzaine :

📌 Exemples concrets :

- **1 mole d'atomes de carbone** = 6,022 × 10²³ atomes de C

- **1 mole de molécules d'eau** = 6,022 × 10²³ molécules H₂O

- **2 moles d'atomes de fer** = 2 × 6,022 × 10²³ = 1,204 × 10²⁴ atomes de Fe

### 3️⃣ L'u.m.a. : l'unité pour peser un atome

**Définition :** L'**unité de masse atomique** (u.m.a. ou u) = 1/12 de la masse d'un atome de ¹²C

**🔬 Pourquoi cette unité bizarre ?**

Parce que la masse réelle d'un atome est **ridiculement petite** :

- 1 atome de carbone ≈ 1,99 × 10⁻²³ grammes (illisible !)

- Au lieu de ça, on dit : 1 atome de ¹²C = **12 u.m.a.** (facile !)

💡 Règle pratique : **1 u.m.a. ≈ masse d'1 proton ≈ masse d'1 neutron**

Donc : masse d'un atome (en u.m.a.) ≈ A (nombre de nucléons)

📌 Exemples :

- ¹H (1 proton, 0 neutron) ≈ **1 u.m.a.**

- ¹²C (6 protons, 6 neutrons) = **12 u.m.a.** (par définition)

- ⁵⁶Fe (26 protons, 30 neutrons) ≈ **56 u.m.a.**

### 4️⃣ La masse molaire : le lien entre les deux mondes

**Définition :** La **masse molaire M** = masse (en grammes) d'une mole d'atomes

✨ Formule magique : M (en g/mol) = A (nombre de masse)

**💡 Pourquoi c'est magique ?**

Le nombre A (combien de nucléons) te donne **directement** combien pèsent 6,022 × 10²³ atomes en grammes !

📌 Exemples :

- **¹²C** : A = 12 → **1 mole** (= 6,022×10²³ atomes) pèse **12 grammes**

- **⁵⁶Fe** : A = 56 → **1 mole** pèse **56 grammes**

- **¹H** : A = 1 → **1 mole** pèse **1 gramme**

🎯 Calcul pratique avec la formule **n = m / M** :

Tu pèses **24 g de carbone** → combien de moles ?

• M(C) = 12 g/mol (car A = 12)

• n = 24 / 12 = **2 moles**

• Soit **2 × 6,022×10²³ = 1,2×10²⁴ atomes** !

### Masse atomique d'un élément : la moyenne des isotopes

**🤔 Le problème :** Imagine que tu achètes un sac de "carbone naturel" en laboratoire. Ce sac ne contient pas QUE du ¹²C. En réalité, il y a un mélange :

- 98,9% des atomes sont du ¹²C (masse = 12)

- 1,1% des atomes sont du ¹³C (masse = 13)

**❓ Question :** Si tu pèses ce mélange, quelle masse vas-tu mesurer ?

**💡 Réponse :** Tu vas mesurer une **moyenne** ! Pas exactement 12, pas exactement 13, mais quelque chose entre les deux (plus proche de 12 car il y en a beaucoup plus).

#### Comment calculer cette moyenne ?

C'est comme calculer une moyenne de notes, mais où certaines notes comptent plus que d'autres.

**Exemple concret avec des notes :**

Si 90 élèves ont eu 15/20 et 10 élèves ont eu 10/20, la moyenne de classe n'est pas (15+10)/2 = 12,5.

Il faut tenir compte qu'il y a **beaucoup plus** d'élèves à 15 qu'à 10 :

Moyenne = (90 × 15 + 10 × 10) / (90 + 10) = 1450 / 100 = **14,5**

On dit que c'est une **"moyenne pondérée"** = une moyenne où on tient compte des quantités.

#### Application aux isotopes du carbone

**Données :**

- ¹²C : 99% des atomes (masse = 12 u.m.a.)

- ¹³C : 1% des atomes (masse = 13 u.m.a.)

**Calcul de la masse atomique moyenne :**

M(carbone) = (99 × 12 + 1 × 13) / 100

M(carbone) = (1188 + 13) / 100

M(carbone) = 1201 / 100

M(carbone) = **12,01 u.m.a.🔑 Conclusion :** Quand tu regardes le tableau périodique et que tu vois "C = 12,011", ce n'est pas une erreur ! C'est la **masse moyenne** en tenant compte du mélange naturel d'isotopes. (On a arrondi les pourcentages à 99/1 pour le calcul mental — les vraies valeurs sont 98,9/1,1 mais le résultat change à peine.)

#### Formule générale

Pour n'importe quel élément avec plusieurs isotopes :

**Masse atomique moyenne = (% isotope 1 × masse 1 + % isotope 2 × masse 2 + ...) / 100**

Note : Dans certains livres, tu verras cette formule écrite M = Σ(αᵢ × Mᵢ) / Σαᵢ. C'est juste une notation mathématique compacte qui dit exactement la même chose.

✏️ **À toi !** — Le cuivre a deux isotopes : ⁶³Cu (70 %) et ⁶⁵Cu (30 %).

❓ Calcule la masse atomique moyenne du cuivre.

💡 Voir la correction

M = 0,70 × 63 + 0,30 × 65

M = 44,1 + 19,5 = **63,6 u** ✅

(Astuce mentale : 70 % de 63 → 63 − 30 % de 63 = 63 − 18,9 = 44,1 ; et 30 % de 65 → 3 × 6,5 = 19,5)

(Valeur tabulée : 63,55 u — très proche, les vrais pourcentages sont 69,17/30,83)

#### 🧬 Équivalence fondamentale

**M(u.m.a.) = M(g·mol⁻¹) ≈ A**
La masse d'un atome en u.m.a. est numériquement égale à sa masse molaire en g·mol⁻¹. Ainsi, 1 mole de ¹²C pèse 12 g, 1 mole de ¹³C pèse 13 g.

## V. Le modèle de Bohr : niveaux d'énergie quantifiés

En 1913, le physicien danois Niels Bohr propose un modèle révolutionnaire pour expliquer comment l'électron se comporte dans l'atome d'hydrogène. Ce modèle est simplifié (on sait aujourd'hui qu'il n'est pas tout à fait exact), mais il reste **essentiel en première année** car il introduit une idée fondamentale : **l'énergie est quantifiée**.

### 🤔 Qu'est-ce que "quantifié" veut dire ?

**Analogie simple :** Imagine un escalier.

- Tu peux être sur la marche 1, la marche 2, la marche 3... mais **jamais entre deux marches**

- C'est pareil pour l'électron : il peut avoir certaines énergies précises (comme des marches), mais pas n'importe quelle énergie

On dit que l'énergie est **"quantifiée"** = elle ne peut prendre que certaines valeurs bien définies, pas des valeurs continues.

### 📐 Le principe du modèle de Bohr (version simple)

**Attention :** Ce modèle ne marche que pour l'**hydrogène (H)** et les atomes qui lui ressemblent (= qui ont **1 seul électron**, comme He⁺, Li²⁺...).

**Les 3 idées principales :1️⃣ L'électron tourne autour du noyau sur des "orbites" circulaires**

Comme une planète autour du Soleil. Chaque orbite a un rayon bien précis.

**2️⃣ Chaque orbite correspond à un niveau d'énergie**

Plus l'orbite est grande (loin du noyau), plus l'énergie est élevée (moins négative).

**3️⃣ On numérote ces orbites avec "n"**

n = 1 → orbite la plus proche (énergie la plus basse = état fondamental)

n = 2, 3, 4... → orbites de plus en plus loin (états excités)

### 🔢 Les formules à connaître

Pour calculer l'énergie et le rayon de chaque niveau, Bohr a établi deux formules. Regardons-les en détail :

#### 1️⃣ Formule de l'énergie

**Pour l'hydrogène (H) :** Eₙ = **−13,6 / n²💡 Comment la lire :**

- **−13,6** : c'est l'énergie de l'état fondamental (n=1) en eV → valeur à retenir absolument !

- **n²** au dénominateur : plus n augmente, plus on divise par un grand nombre, donc l'énergie augmente (devient moins négative)

- Le signe **−** (négatif) : rappelle que l'électron est lié au noyau

**Exemples de calcul :**

- n = 1 : E₁ = −13,6 / 1² = **−13,6 eV**

- n = 2 : E₂ = −13,6 / 4 = **−3,4 eV** (4 fois moins profond)

- n = 3 : E₃ = −13,6 / 9 = **−1,51 eV** (9 fois moins profond)

**Pour les autres atomes à 1 électron (He⁺, Li²⁺...) :** Eₙ = **−13,6 × Z² / n²💡 Différence :** On multiplie par Z² (numéro atomique au carré).

- Pourquoi ? Plus Z est grand, plus le noyau est chargé (+), plus il attire fort l'électron → l'électron est plus lié → énergies plus négatives

- Exemple : He⁺ (Z=2) → E₁ = −13,6 × 4 / 1 = **−54,4 eV** (4 fois plus lié que H !)

#### 2️⃣ Formule du rayon

**Pour l'hydrogène (H) :** rₙ = **0,53 × n²💡 Comment la lire :**

- **0,53** : c'est le rayon de l'orbite n=1 (en Ångström, Å = 10⁻¹⁰ m) → valeur à retenir !

- **n²** : plus n augmente, plus l'orbite est grande (l'électron s'éloigne du noyau)

**Exemples de calcul :**

- n = 1 : r₁ = 0,53 × 1 = **0,53 Å**

- n = 2 : r₂ = 0,53 × 4 = **2,12 Å** (4 fois plus loin)

- n = 3 : r₃ = 0,53 × 9 = **4,77 Å** (9 fois plus loin)

**Pour les autres atomes à 1 électron (He⁺, Li²⁺...) :** rₙ = **0,53 × n² / Z💡 Différence :** On divise par Z.

- Pourquoi ? Plus Z est grand, plus le noyau attire fort → l'électron est "tiré" plus près du noyau → rayon plus petit

- Exemple : He⁺ (Z=2) → r₁ = 0,53 / 2 = **0,265 Å** (2 fois plus petit que H !)

#### 🔑 Astuce de mémorisation

**Pour H (hydrogène) :** Retiens juste 2 valeurs magiques :

- **−13,6 eV** (énergie du niveau n=1)

- **0,53 Å** (rayon du niveau n=1)

Ensuite, pour n'importe quel niveau n, multiplie simplement par **n²** !

**Pour He⁺, Li²⁺, Be³⁺... :** Même chose, mais pense à ajuster avec Z :

- Énergie → multiplie par **Z²** (noyau plus chargé = plus d'attraction)

- Rayon → divise par **Z** (plus d'attraction = électron plus proche)

### ⚡ Les niveaux d'énergie de l'hydrogène

**💡 Important à comprendre :** Les énergies sont **négatives**. Pourquoi ?

Parce qu'on prend comme référence E = 0 quand l'électron est **infiniment loin** du noyau (= libre). Comme l'électron est **attiré** par le noyau (attraction électrique), pour le rapprocher il faut "descendre" en énergie → énergie négative = l'électron est "prisonnier" du noyau.

**Voici les valeurs à retenir pour H :**

- **n = 1** (couche K) : E₁ = **−13,6 eV**

→ C'est l'**état fondamental** (le plus stable, énergie la plus basse)

- **n = 2** (couche L) : E₂ = −13,6 / 4 = **−3,4 eV**

→ État excité (moins stable)

- **n = 3** (couche M) : E₃ = −13,6 / 9 = **−1,51 eV**

→ État excité

- **n = 4** (couche N) : E₄ = −13,6 / 16 = **−0,85 eV**

→ État excité

- **n → ∞** : E = **0 eV**

→ L'électron est libre, l'atome est **ionisé** (H⁺)

**🔑 Ce qu'il faut retenir :**

- Plus n augmente, plus l'énergie augmente (devient moins négative, se rapproche de 0)

- L'état fondamental (n=1) a l'énergie la plus basse (−13,6 eV)

- Pour arracher l'électron (ioniser H), il faut fournir **13,6 eV**

#### 🧬 États de l'atome

**État fondamental** (n = 1) : énergie la plus basse, atome au repos, le plus stable.

**États excités** (n = 2, 3, 4…) : énergie plus haute, atome instable, il va rapidement retomber.

**État ionisé** (n → ∞) : E = 0, l'électron est arraché du noyau. L'énergie d'ionisation de H est donc **13,6 eV**.

#### ⚠️ Limites du modèle de Bohr

Le modèle de Bohr fonctionne **uniquement pour les atomes à 1 électron**. Dès qu'il y a plusieurs électrons, les interactions e⁻/e⁻ rendent le modèle inapplicable → il faut passer au **modèle quantique** (avec les orbitales atomiques et les nombres quantiques).

## VI. Transitions électroniques : absorption et émission d'énergie

Maintenant qu'on sait que l'électron peut être sur différents niveaux d'énergie, posons-nous la question : **comment passe-t-il d'un niveau à un autre ?**

### 🤔 La logique physique des transitions

Rappelle-toi : le noyau (chargé +) **attire** l'électron (chargé −). C'est comme la gravité pour une balle :

**1️⃣ Pour MONTER (s'éloigner du noyau) :**

- L'électron doit **lutter contre l'attraction** du noyau

- Il a besoin d'énergie pour s'éloigner → il doit **ABSORBER de l'énergie**

- C'est comme soulever une balle : tu dois fournir de l'énergie

- **Exemple :** Électron passe de n=1 → n=2 en absorbant un photon d'énergie

**2️⃣ Pour DESCENDRE (se rapprocher du noyau) :**

- L'électron est **naturellement attiré** vers le noyau (comme une balle qui tombe)

- En tombant, il perd de l'énergie → il **ÉMET de l'énergie**

- Cette énergie part sous forme de lumière (photon)

- **Exemple :** Électron tombe de n=3 → n=1 en émettant un photon lumineux

#### 💡 Résumé simple

**📝 Notation importante :**

- **nᵢ** (ou n i ) = niveau **initial** (là où l'électron **commence**)

- **nf** (ou n f ) = niveau **final** (là où l'électron **arrive**)

**ABSORPTION** (monter de niveau) : l'électron **reçoit de l'énergie** (photon entrant)

→ L'électron **démarre en bas** (nᵢ = 1, 2, 3...) et **finit plus haut** (nf = 2, 3, 4...)

Exemple : nᵢ = 1 → nf = 3 (électron monte de n=1 à n=3)

**ÉMISSION** (descendre de niveau) : l'électron **libère de l'énergie** (photon sortant = lumière !)

→ L'électron **démarre en haut** (nᵢ = 3, 4, 5...) et **finit plus bas** (nf = 1, 2, 3...)

Exemple : nᵢ = 4 → nf = 2 (électron tombe de n=4 à n=2)

### ⚡ Énergie d'une transition

Que ce soit en absorption ou émission, l'énergie échangée correspond **exactement** à la différence d'énergie entre les deux niveaux :

**Énergie échangée :**

|ΔE| = |Ef − Eᵢ|

💡 Cette énergie est transportée par un **photon** (grain de lumière) :

- **Absorption :** l'atome capte un photon → l'électron monte

- **Émission :** l'atome émet un photon (lumière !) → l'électron descend

### 🧮 Formule de transition (directe)

Jusqu'ici, pour calculer l'énergie d'une transition, on faisait :

1️⃣ Calculer Eᵢ = −13,6/nᵢ² eV

2️⃣ Calculer Ef = −13,6/nf² eV

3️⃣ Faire ΔE = Ef − Eᵢ

**💡 Il existe un raccourci !** Une formule qui fait tout d'un coup :

#### 📐 Formule de transition directe

**Pour l'hydrogène (H) :ΔE = −13,6 × (1/nf² − 1/nᵢ²) eVPour les hydrogénoïdes (He⁺, Li²⁺...) :ΔE = −13,6 × Z² × (1/nf² − 1/nᵢ²) eV**

#### 🔍 Décryptage de la formule

**D'où ça vient ?**

ΔE = Ef − Eᵢ

ΔE = (−13,6/nf²) − (−13,6/nᵢ²)

ΔE = −13,6/nf² **+** 13,6/nᵢ²

ΔE = −13,6 × (1/nf² − 1/nᵢ²) ✅

**Rappel important :**

- **nᵢ** = niveau **initial** (d'où part l'électron)

- **nf** = niveau **final** (où arrive l'électron)

**💡 Interprétation du signe de ΔE :**

- Si **ΔE > 0** (positif) : Ef > Eᵢ → l'électron **monte** en énergie → **absorption**

- Si **ΔE

- Pour l'énergie du photon, on prend toujours **|ΔE|** (valeur absolue = valeur positive)

**Étape 1 :** Identifier nᵢ et nf

ΔE = −13,6 × (1/1² − 1/3²) = −13,6 × (1 − 1/9)

### 🌈 Énergie du photon : le lien avec la lumière

On sait maintenant calculer **|ΔE|** pour une transition. Mais cette énergie est transportée par un **photon** (grain de lumière), et chaque photon a des propriétés physiques : une **fréquence ν** et une **longueur d'onde λ**.

**🤔 Question clé :** Comment relier l'énergie ΔE à la fréquence ou la longueur d'onde du photon émis/absorbé ?

#### 📐 Formules de l'énergie d'un photon

L'énergie d'un photon peut se calculer de **deux façons équivalentes** :

**ΔE = h × ν** ou **ΔE = h × c / λOù :**

- **h** = 6,63 × 10⁻³⁴ J·s (constante de Planck)

- **c** = 3 × 10⁸ m/s (vitesse de la lumière)

- **ν** (nu) 〰️ = fréquence du photon en Hz

- **λ** (lambda) = longueur d'onde du photon en mètres

**🚨 Attention aux unités !** Les constantes h et c utilisent des **Joules (J)**, des **mètres (m)** et des **secondes (s)**. Toutes tes valeurs doivent être dans ces unités pour que les calculs fonctionnent !

#### 🔄 Comment utiliser ces formules ?

**Tu connais ΔE → Tu veux trouver λ (longueur d'onde) :**

ΔE = h × c / λ ⇒ **λ = h × c / ΔE**

→ Résultat en mètres si ΔE est en Joules

**Tu connais ΔE → Tu veux trouver ν (fréquence) :**

ΔE = h × ν ⇒ **ν = ΔE / h**

→ Résultat en Hz si ΔE est en Joules

**⚠️ Conversion OBLIGATOIRE :1 eV = 1,6 × 10⁻¹⁹ J**

Les énergies de Bohr sont en **eV**, mais les formules de photons utilisent des **Joules** !

**→ Multiplie toujours ΔE (en eV) par 1,6×10⁻¹⁹ pour avoir des Joules avant de calculer λ ou ν !**

#### ⚠️ Piège classique — Cohérence des unités

**Erreur classique :** Utiliser directement ΔE en eV dans les formules λ = hc/ΔE ou ν = ΔE/h.

**✅ La bonne méthode :**

- Calculer ΔE avec Bohr → tu obtiens des **eV**

- Convertir en Joules : ΔE(J) = ΔE(eV) × 1,6×10⁻¹⁹

- Utiliser λ = (6,63×10⁻³⁴ × 3×10⁸) / ΔE(J) → tu obtiens λ en **mètres**

- Si besoin, convertir λ en nm : 1 m = 10⁹ nm

**Astuce :** Si ton λ sort avec des valeurs bizarres (genre 10²⁰ ou 10⁻⁴⁰), c'est que tu as oublié la conversion eV → J ! 😱

#### 💡 Conseil — Constantes à connaître

Souvent les constantes sont données au début d'un énoncé d'examen, **MAIS** la vitesse de la lumière **c** et la constante de Planck **h** sont des **incontournables à connaître (presque par cœur)**. Ne compte pas toujours sur l'énoncé pour te les donner ! 😉

**🔗 Application concrète :**

Grâce à ces formules, si tu connais |ΔE| (en eV), tu peux calculer la **longueur d'onde λ** du photon émis. Et selon la valeur de λ, tu sauras si le photon est dans l'UV, le visible, ou l'infrarouge ! C'est ce qu'on va voir maintenant avec les **séries spectrales**. 👇

### 🌈 Les séries spectrales : classification des transitions

On vient de voir qu'un électron qui retombe émet un photon avec une longueur d'onde λ précise. Mais il y a énormément de transitions possibles : 2→1, 3→1, 4→1, 3→2, 4→2, 5→3, etc.

**🤔 Comment s'y retrouver ?**

Les scientifiques ont remarqué quelque chose d'intelligent : si on **regroupe les transitions selon leur niveau d'arrivée nf**, on obtient des familles de raies qui tombent toutes dans le **même domaine spectral** (UV, visible, ou IR) !

Ces familles s'appellent des **séries spectrales**. Il y en a 3 principales à connaître :

#### 📊 Les 3 séries spectrales principales

**1️⃣ Série de Lyman (vers n = 1) :**

- **Transitions :** Toutes les retombées vers n f = 1 (2→1, 3→1, 4→1, 5→1...)

- **Domaine :** Ultraviolet (UV) — λ < 400 nm

- **Pourquoi UV ?** Les transitions vers n=1 ont un grand ΔE → photons très énergétiques → courte longueur d'onde

- **💡 Mnémotechnique :L**yman → n = **1** (L = 1 bâton vertical)

**2️⃣ Série de Balmer (vers n = 2) :**

- **Transitions :** Toutes les retombées vers n f = 2 (3→2, 4→2, 5→2, 6→2...)

- **Domaine :** Visible — 400 nm < λ < 700 nm

- **Pourquoi visible ?** ΔE moyen → photons d'énergie moyenne → dans la plage visible pour l'œil humain !

- **💡 Mnémotechnique :B**almer → **B**ien visible

- **🎨 Remarque :** C'est cette série qui donne les belles couleurs de l'hydrogène (rouge, bleu, violet...)

**3️⃣ Série de Paschen (vers n = 3) :**

- **Transitions :** Toutes les retombées vers n f = 3 (4→3, 5→3, 6→3...)

- **Domaine :** Infrarouge (IR) — λ > 700 nm

- **Pourquoi IR ?** Petit ΔE → photons peu énergétiques → grande longueur d'onde (chaleur)

- **💡 Mnémotechnique :P**aschen → n = **3** (P = 3ᵉ lettre de l'alphabet après M)

Plus l'écart d'énergie ΔE est grand, plus le photon est énergétique (haute fréquence ν, courte longueur d'onde λ). Les transitions vers n = 1 (Lyman) sont les plus énergétiques (UV), celles vers n = 2 (Balmer) produisent de la lumière visible, et celles vers n = 3 (Paschen) sont en infrarouge.
