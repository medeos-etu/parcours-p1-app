Placer un élément à partir de sa configuration

On te donne un numéro atomique.

Tu dois rendre une case précise du tableau.

La fiche précédente t'a montré comment le tableau est construit : la ligne donne la couche n, la colonne donne les électrons de valence, le bloc dit quelle sous-couche se remplit. On fait maintenant le chemin inverse — on part d'un Z et on retrouve la case. Bonne nouvelle : il suffit d'écrire sa configuration électronique, tu sais déjà le faire.

Avant ça, un par-cœur qui rapporte. Les trois premières lignes du tableau tombent systématiquement au concours : les avoir en tête t'évite de recompter à chaque question.

Le mnémo — les 3 premières périodesPériode 1 & 2 : « Henri Hébert Lit Beaucoup, Boit du Café N'importe Où, Fume Neuf pipes » → H He | Li Be B C N O F Ne
Période 3 : « Napoléon Mangea Allégrement Six Poulets Sans Claquer d'Argent » → Na Mg Al Si P S Cl Ar
🎯 Le trick qui tue : une fois ces 3 lignes connues, pour retrouver le Z d'un élément de la période suivante dans la même colonne, tu fais +18 ! Exemple : Cl (période 3) = Z = 17 → Br (période 4) = 17 + 18 = 35 → I (période 5) = 35 + 18 = 53
PériodeLes 18 premiers éléments, avec leur Z
1H (1), He (2)
2Li (3), Be (4), B (5), C (6), N (7), O (8), F (9), Ne (10)
3Na (11), Mg (12), Al (13), Si (14), P (15), S (16), Cl (17), Ar (18)

Dix-huit éléments à connaître — et pour descendre d'une période dans la même colonne, tu ajoutes 18.

Retrouver la position, en 3 gestes
  1. 1 Écris sa configuration électronique. Rien d'autre, et surtout pas de tableau sous les yeux. Cl (Z = 17) → [Ne] 3s² 3p⁵.
  2. 2 La période = le n le plus élevé de la config de valence. Sur 3s² 3p⁵, le n le plus élevé vaut 3 → période 3.
  3. 3 Le bloc, puis la colonne. La dernière sous-couche remplie donne le bloc : ici 3p → bloc p. Et le groupe = le nombre d'e⁻ de valence (blocs s et p ; pour le bloc d, c'est la position dans le bloc) : 2 + 5 = 7 e⁻ de valence. Dans le bloc p, les colonnes vont de 13 à 18 → colonne 17.

Résultat pour le chlore : période 3, bloc p, colonne 17. Trois gestes, aucune mémorisation. À toi maintenant — prends le temps de le faire sur ton brouillon avant de lire la correction.

✏️ Mini-exercice Le sélénium a pour numéro atomique Z = 34. 1) Écris sa configuration électronique.  2) Dans quelle période, quel bloc et quelle colonne se trouve-t-il ?
La correction
  1. 1 La configuration. Se (Z = 34) : 1s² 2s² 2p⁶ 3s² 3p⁶ 4s² 3d¹⁰ 4p⁴ → config de valence : 4s² 4p⁴.
  2. 2 La période. n le plus élevé = 4 → période 4.
  3. 3 Le bloc. Dernière sous-couche remplie = 4p → bloc p. Le 3d¹⁰ est rempli et complet : il ne décide pas du bloc.
  4. 4 La colonne. Nombre d'e⁻ de valence = 2 + 4 = 6 → colonne 16.

Le cours pose une troisième question sur le sélénium — à quelle famille il appartient et ce qu'il va faire pour se stabiliser. C'est le sujet de la fiche suivante ; ici, on s'arrête à la case.

Ne cherche jamais à retenir la position d'un élément : retrouve-la. Toujours le même ordre — la configuration, puis le n le plus élevé (la période), puis la dernière sous-couche remplie (le bloc) et le nombre d'électrons de valence (la colonne). Avec les 18 premiers éléments en tête et le +18, tu retombes sur n'importe quelle case sans avoir appris le tableau par cœur.
À retenir Période = le n le plus élevé de la configuration de valence. Bloc = la dernière sous-couche remplie. Groupe = le nombre d'électrons de valence (blocs s et p), ou la position dans le bloc d. L'exemple type : Cl (Z = 17) → [Ne] 3s² 3p⁵ → période 3, bloc p, colonne 17.
Le piège Dans le bloc p, le numéro de colonne n'est pas le compteur d'électrons : ces colonnes sont numérotées 13 à 18. Cl a 7 e⁻ de valence et tombe en colonne 17 ; Se en a 6 et tombe en colonne 16. Le nombre d'électrons de valence décide, mais la colonne se lit sur le tableau.
