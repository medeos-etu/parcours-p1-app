l, le nombre quantique azimutal

n donnait l'étage. l donne la forme de l'orbitale.

Et surtout : l ne prend pas n'importe quelle valeur — il dépend de n.

On vient de poser le premier niveau de l'adresse : n, la couche. Le deuxième s'appelle l, le nombre quantique azimutal — ou secondaire. Son rôle : déterminer la forme de l'orbitale (s, p, d, f). Tu l'as déjà croisé en apprenant à lire le nom d'une orbitale : dans « 1s », « 2p » ou « 3d », le chiffre c'est n, la lettre c'est l. On reprend cette correspondance, cette fois du côté du nombre.

Valeur de lType d'orbitaleForme
l = 0orbitale de type ssphère (boule)
l = 1orbitale de type p2 lobes (haltère)
l = 2orbitale de type d4 lobes (trèfle)
l = 3orbitale de type fforme complexe (8 lobes)

📌 Correspondance à connaître par cœur dans les deux sens : d'une lettre, tu dois retrouver le l ; d'un l, la lettre.

Vient ensuite la contrainte qui fait toute la difficulté de ce nombre-là. Contrairement à n, l ne se choisit pas librement : ses valeurs s'arrêtent une marche avant n.

Valeurs possibles de l l = 0, 1, 2, … jusqu'à (n − 1) ⚠️ Règle importante : l dépend de n ! On ne peut pas avoir n'importe quelle valeur de l pour un n donné.

Concrètement, cette règle décide des sous-couches qui existent sur chaque couche. Voilà ce que ça donne pour les quatre premières.

Couche (n)Valeurs de l possiblesSous-couches disponibles
n = 1l = 0 seulement1s uniquement
n = 2l = 0 ou 12s et 2p
n = 3l = 0, 1 ou 23s, 3p et 3d
n = 4l = 0, 1, 2 ou 34s, 4p, 4d et 4f
L'analogie — l'appartement à cet étagel = 🚪 L'appartement à cet étage. 💡 Astuce : pour la couche n, il y a n types d'orbitales possibles (n valeurs de l différentes).

Lis maintenant le tableau dans le sens de la contrainte, c'est là qu'il devient utile. Pour n = 1, l ne peut valoir que 0 : il n'existe qu'une seule sous-couche, 1s. Une orbitale « 1p » demanderait l = 1, alors que le maximum autorisé vaut n − 1 = 0 — elle n'existe pas. Même raisonnement pour « 2d » (il faudrait l = 2, le maximum est 1) ou pour « 3f » (il faudrait l = 3, le maximum est 2).

Devant un nom d'orbitale, fais le test dans cet ordre : lis le chiffre (c'est n), lis la lettre (elle donne l : s = 0, p = 1, d = 2, f = 3), puis vérifie que l ≤ n − 1. Si la lettre réclame un l trop grand pour son chiffre, la sous-couche n'existe pas et la proposition est fausse — inutile d'aller plus loin.

Tu sais donc quelles sous-couches existent. Reste à savoir combien d'orbitales se cachent dans chacune d'elles : c'est le travail du troisième nombre quantique.

À retenir l détermine la forme de l'orbitale. Ses valeurs vont de 0 à n − 1 : elles dépendent donc de n. Correspondance : 0 → s, 1 → p, 2 → d, 3 → f. Sur la couche n, il y a n sous-couches possibles : n = 1 → 1s · n = 2 → 2s, 2p · n = 3 → 3s, 3p, 3d · n = 4 → 4s, 4p, 4d, 4f.
Le piège l ne monte pas jusqu'à n : il s'arrête à n − 1. Pour n = 2, l vaut 0 ou 1, jamais 2. Une proposition qui parle d'une orbitale « 2d », « 1p » ou « 3f » est fausse pour cette seule raison, avant même de regarder le reste.
