Le modèle de Bohr : des orbites quantifiées

L'électron ne choisit pas son énergie : il n'a que des marches.

Il monte en absorbant, il descend en émettant.

En 1913, le physicien danois Niels Bohr propose un modèle pour expliquer comment l'électron se comporte dans l'atome d'hydrogène. Il est simplifié, mais il apporte une idée fondamentale : l'énergie est quantifiée. Imagine un escalier — tu peux être sur la marche 1, la 2, la 3, mais jamais entre deux marches. C'est pareil pour l'électron : il ne peut prendre que certaines énergies bien précises. Attention, ce modèle ne vaut que pour l'hydrogène et les atomes qui n'ont qu'un seul électron (He⁺, Li²⁺…).

Une orbite = un niveau d'énergie — à gauche la distance au noyau, à droite l'énergie correspondante.

Ce que dit le modèle, en 5 idées
  1. 1 Des orbites numérotées par n. L'électron tourne autour du noyau sur des orbites circulaires, comme une planète autour du Soleil. On les numérote : n = 1 est l'orbite la plus proche du noyau (rayon 0,53 Å), puis n = 2, 3, 4… de plus en plus loin.
  2. 2 Une énergie par niveau — et elle est négative. On prend comme référence E = 0 quand l'électron est infiniment loin, donc libre. Comme le noyau l'attire, un électron lié a une énergie négative : il est « prisonnier ». Pour l'hydrogène : n = 1 → −13,6 eV, n = 2 → −3,4 eV, n = 3 → −1,51 eV, n = 4 → −0,85 eV, et n → ∞ → 0 eV.
  3. 3 Plus n grandit, plus l'énergie monte. Attention au sens : « plus haut » veut dire moins négatif, donc plus proche de 0. Et les niveaux se resserrent à mesure que n augmente.
  4. 4 Trois états à distinguer. État fondamental (n = 1) : énergie la plus basse, atome au repos, le plus stable. États excités (n = 2, 3, 4…) : instables, l'électron va vite retomber. État ionisé (n → ∞) : l'électron est arraché — il faut fournir 13,6 eV pour ioniser un atome d'hydrogène.
  5. 5 Monter = absorber, descendre = émettre. Pour s'éloigner du noyau, l'électron lutte contre l'attraction : il doit absorber un photon. En retombant, il perd de l'énergie et émet un photon — de la lumière. Dans les deux cas, l'énergie échangée vaut exactement l'écart entre les deux niveaux : |ΔE| = |Ef − Ei|.
Les retombées se rangent en séries spectrales, selon leur niveau d'arrivée : vers n = 1 c'est la série de Lyman, dans l'ultraviolet ; vers n = 2 la série de Balmer, dans le visible (Balmer → Bien visible) ; vers n = 3 la série de Paschen, dans l'infrarouge. Logique : plus l'écart d'énergie est grand, plus le photon est énergétique.
À retenir L'énergie de l'électron est quantifiée : seules certaines valeurs existent. n = 1 = état fondamental (−13,6 eV pour H), n ≥ 2 = états excités, n → ∞ = atome ionisé à 0 eV.
Le piège Les énergies sont négatives : « énergie plus haute » signifie moins négative. Et le modèle de Bohr ne s'applique qu'aux atomes à un seul électron — avec plusieurs électrons, leurs interactions le rendent inapplicable.
