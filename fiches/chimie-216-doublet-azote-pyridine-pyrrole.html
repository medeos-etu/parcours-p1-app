Le doublet de l'azote : dedans ou dehors ?

L'azote a toujours un doublet libre.

Toute la question, c'est de savoir s'il monte dans le cycle — ou s'il reste dehors.

Tu sais trier un composé entre aromatique, anti-aromatique et non aromatique. Le critère qui tranche le plus souvent, c'est le quatrième : 4n + 2 e⁻ π. Encore faut-il savoir compter ces e⁻ π — et le seul point vraiment dur du comptage, c'est l'azote. On le règle ici, avant la méthode.

Deux rappels rapides. Un doublet = 2 électrons ensemble, c'est tout : liant s'ils sont partagés entre deux atomes (le trait d'une liaison), libre (= non liant) s'ils restent sur un seul atome (le ∶ dessiné à côté). Et une double liaison n'est pas deux doublets libres : du point de vue de chaque atome, une C=C ne coûte que 1 e⁻ de plus qu'une liaison simple.

Le cœur du sujet, maintenant : le « budget » des e⁻ de valence. Chaque atome dépense son stock un par un pour ses liaisons — ce qui reste, c'est un doublet libre.

Le budget : carbone contre azote
Atome Budget Ce qu'il dépense Ce qui reste
Carbone (benzène) 4 e⁻ 3 liaisons σ (voisin de gauche, voisin de droite, H) + 1 e⁻ pour la liaison π (l'orbitale p, le « manège ») 0 → pas de doublet libre
Azote 5 e⁻ 1 e⁻ de plus que le C, mais seulement 3 liaisons σ 2 e⁻ → 1 doublet libre, toujours

Le « manège », c'est le nuage π du cycle : l'orbitale p perpendiculaire au plan, dans laquelle les électrons tournent.

Le N a donc toujours son doublet. Reste une seule question : où va-t-il ? Deux cas — et deux molécules au comportement opposé.

Où part le doublet de l'azote — les deux cas
  1. 1 Pyridine — le N fait une double liaison C=N. Son budget : 1 e⁻ pour la σ avec le C de gauche, 1 e⁻ pour la σ avec le C de droite, 1 e⁻ pour la liaison π du C=N (qui entre dans le manège) → il reste 2 e⁻ = 1 doublet libre. Son orbitale p est déjà prise par la liaison π → le doublet reste dans le plan, HORS du manège. Il reste donc disponible → N est basique (il peut capter un H⁺).
  2. 2 Pyrrole — le N n'a que des liaisons simples. Son budget : 1 e⁻ pour la σ avec le C de gauche, 1 e⁻ pour celle avec le C de droite, 1 e⁻ pour la σ avec le H (N−H) → il reste là aussi 2 e⁻ = 1 doublet libre. Pourquoi entre-t-il, cette fois ? Parce que le N n'a pas utilisé d'e⁻ pour une liaison π → son orbitale p est libre → le doublet s'y installe, DANS le manège → +2 e⁻ π. Le doublet est pris → N n'est plus basique.

Le mnémo — le double R du pyrroleLe pyrrole a un double R → son doublet entre en double dans le cycle (manège 🎠). La pyridine n'a qu'un seul R → son doublet reste seul dehors (spectateur 🧍 → basique).
Devant un hétérocycle azoté, ne regarde pas le doublet — il est toujours là. Regarde l'orbitale p du N. Une même observation te donne alors deux réponses de QCM d'un coup : le compte des e⁻ π et la basicité de l'azote.
À retenir Le carbone dépense ses 4 e⁻ et n'en garde aucun. L'azote a 5 e⁻ pour seulement 3 liaisons σ → il lui reste toujours 1 doublet libre. Pyridine : doublet dans le plan, hors du π → N basique. Pyrrole : doublet dans l'orbitale p, dans le π (+2 e⁻ π) → N non basique.
Le piège « Le doublet de l'azote participe toujours à l'aromaticité. » → FAUX. Pyrrole : doublet dans le cycle (il participe, N non basique). Pyridine : doublet hors du cycle (il ne participe pas, N basique). Il faut vérifier l'orientation de l'orbitale.
