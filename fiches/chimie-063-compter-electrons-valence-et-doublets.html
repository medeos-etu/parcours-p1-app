Étapes 1 et 2 : compter N, puis n = N/2

Avant de dessiner quoi que ce soit, on compte les briques.

D'abord N, le total d'électrons de valence. Puis n, le nombre de doublets à placer.

Les fiches précédentes t'ont dit ce qu'est un schéma de Lewis : des doublets liants (un trait entre deux atomes) et des doublets non liants (deux points sur un atome), placés pour que chaque atome atteigne son octet — ou son duet pour H. Elles t'ont aussi donné les deux dérogations à cette règle : la lacune électronique en dessous de 8, l'hypervalence au-dessus. La théorie est complète. Reste la question qui compte au concours : comment le construire ? À partir d'ici, on déroule une méthode en 7 étapes, dite méthode « avec atome central ». Elle fonctionne pour 100 % des molécules et des ions : maîtrise-la, et tu pourras dessiner n'importe quel Lewis.

L'analogie — construire une maisonDessiner un schéma de Lewis, c'est comme construire une maison : d'abord, on compte les briques disponibles (= les électrons de valence) ; ensuite, on choisit où placer les fondations (= atome central) ; puis on connecte les murs (= liaisons simples) ; on remplit avec les meubles (= doublets non liants) ; et si tout ne rentre pas, on renforce la structure (= liaisons multiples) ; enfin, on vérifie que tout est stable (= charges formelles).

Cette fiche traite les deux premières étapes : le comptage des briques. On les suit sur deux exemples qui vont revenir jusqu'au bout de la méthode — H₂O (molécule neutre) et SO₄²⁻ (ion). Les données de départ : H (1 e⁻ de valence), O (6 e⁻ de valence), S (6 e⁻ de valence).

D'où sortent ces nombres ? Du tableau périodique, le schéma de référence du chapitre — juste en dessous. Il n'est pas là pour décorer : c'est lui qui te fournit, atome par atome, le nombre d'électrons de valence que tu vas additionner.

Étape 1 — Calculer N N = somme des e⁻ de valence de tous les atomes N = le nombre TOTAL d'électrons de valence de tous les atomes présents dans la molécule ou l'ion.
L'ajustement pour les ions
  1. + Ion POSITIF (ex : NH₄⁺, Ca²⁺) → l'ion a PERDU des électrons → soustraire le nombre correspondant à la charge. NH₄⁺ a perdu 1 e⁻ → N = (somme e⁻ de valence) − 1.
  2. − Ion NÉGATIF (ex : Cl⁻, SO₄²⁻) → l'ion a GAGNÉ des électrons → ajouter le nombre correspondant à la charge. Cl⁻ a gagné 1 e⁻ → N = (somme e⁻ de valence) + 1.

H₂O
molécule neutre		1 (H) + 1 (H) + 6 (O)
pas de charge, aucun ajustement		N = 8 e⁻
SO₄²⁻
ion de charge −2		6 (S) + 6×4 (quatre O) + 2 (charge 2−)
= 6 + 24 + 2		N = 32 e⁻

Pour H₂O, on a donc 8 électrons de valence à répartir dans la structure. Pour SO₄²⁻, on ajoute 2 e⁻ parce que l'ion porte une charge globale de −2 : l'ensemble {1 S + 4 O} a gagné 2 électrons par rapport aux atomes neutres.

Étape 2 — Calculer n n = N / 2 Les électrons vont toujours par paires (doublets). Donc on divise N par 2.

Ce nombre n représente TOUS les doublets qu'on devra placer : les liants (les liaisons) et les non liants (ceux qui restent sur les atomes). Pas seulement les liaisons — c'est un total.

Étape 2 — nLe calculRésultat
H₂On = 8 / 24 doublets à placer
SO₄²⁻n = 32 / 216 doublets à placer
Devant un ion, pose-toi les deux questions dans cet ordre : quelle est la charge, et l'ion a-t-il perdu ou gagné des électrons ? Positif → il a perdu → on soustrait. Négatif → il a gagné → on ajoute. Un ajustement raté à l'étape 1 fausse toutes les étapes suivantes : n, les liaisons, les charges formelles. C'est le calcul à vérifier deux fois.
Nombre impair d'e⁻. Si N est impair, ne cherche pas l'erreur de calcul : la molécule possède un e⁻ célibataire (radical). Exemples : NO (11 e⁻), NO₂ (17 e⁻). Ces molécules sont paramagnétiques et très réactives.
À retenir N = somme des e⁻ de valence de tous les atomes, ajustée de la charge : ion positif → on soustrait, ion négatif → on ajoute. Puis n = N/2 = le nombre total de doublets à placer, liants et non liants confondus. H₂O : N = 8 → n = 4. SO₄²⁻ : N = 32 → n = 16.
Le piège n n'est pas le nombre de liaisons. C'est le nombre de tous les doublets — les 4 doublets de H₂O, ce sont 2 liaisons O–H plus 2 doublets non liants sur O. Confondre les deux, c'est se retrouver avec une structure où il manque des électrons.

Les briques sont comptées. Étape suivante : choisir où poser les fondations — c'est-à-dire quel atome se place au centre.
